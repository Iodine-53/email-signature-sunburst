# Icon hosting map — email signature #6 ("Sunburst")

All images hosted remotely so the signature works with absolute URLs in any inbox.
Host: **catbox.moe** (free, no account, direct permanent links).

**Artwork sources:**
- Background (yellow wedge, teal trapezoid/slash/strip, top bar + stripes, divider, icon circles): generated server-side with PIL from pixel measurements of the Fiverr reference — `slices/e6_bg.png`
- Photo: circular slice cut from the reference, light ring baked in — `slices/e6_photo.png`
- Social glyphs: Flaticon UIcons Brands (`fi-brands-twitter`, `fi-brands-facebook`, `fi-brands-instagram`, `fi-brands-linkedin`), rendered server-side in teal #003F5E — attribution https://www.flaticon.com/uicons
